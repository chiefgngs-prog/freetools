Turn your Git history into a visual mind map. See who changed what, when, and why. Paste any git log output. Instant visualization.

Step 1: Generate Git Log

Run this in your repo:

git log --pretty=format:"%H|%an|%ae|%ad|%s" --date=short -50
🧠
Paste your git log and hit Visualize to see your commit history as a mind map.
